# Call Center Performance

> **Business question:** How many calls actually get resolved?

`Operations` · Oct 2024 · `Power BI` · `DAX`

![Call Center Performance](images/call-center.jpg)

## Key findings

- Of **5,000** calls, **81%** were answered and **73%** resolved.
- Average satisfaction is **3.4 / 5**.
- Breakdown by agent, topic and month to spot where service drops.

## About the report

Service-level view for a call center team with agent statistics, calls by topic and monthly volume.
