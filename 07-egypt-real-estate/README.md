# Egypt Real Estate Market

> **Business question:** Where are villas and apartments priced highest?

`Python` · May 2023 · `Python` · `Pandas` · `Power BI`

![Egypt Real Estate Market](images/realestate.jpg)

## Key findings

- Listings across **Cairo, Alexandria and Giza**, for sale and for rent.
- Alexandria villas average **5.5M**, the highest of any location and property type.
- Average price **1.71M** and average area **147.75 m²** across listings.

## About the report

Data cleaned and explored in Python (Pandas, Matplotlib, Seaborn), with written insights for the sale and rent markets, then presented in a Power BI dashboard.
